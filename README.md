\# Go Task API



API REST para gerenciamento de tarefas desenvolvida em Go.



\## Funcionalidades



\- Listar tarefas

\- Criar tarefas

\- Excluir tarefas

\- Respostas em JSON



\## Tecnologias



\- Go

\- HTTP REST API

\- JSON

\- Git e GitHub
